## 🏋️ Gym Tracker – Workout Progress App

Gym Tracker is a **mobile-friendly workout tracking web application** built with **Vue 3 + Vite**.  
It helps users follow a structured **Push–Pull–Legs (PPL)** training program and track daily workouts efficiently.

### ✨ Key Features

- **Guided Training Program**
  - Follows a **Bro Split (Push → Pull → Legs → Repeat)** routine
  - Clearly structured day-wise workout plan

- **Daily Dashboard**
  - Personalized welcome message
  - Daily fitness tips for motivation
  - Quick access to start workouts

- **Workout Tracking**
  - Warm-up and main workout sections
  - Each exercise includes:
    - Sets
    - Reps
    - Editable weight inputs
  - Easy progress entry during workouts

- **Progressive Unlock System**
  - Workouts unlock day by day
  - Encourages consistency and discipline

- **Clean & Responsive UI**
  - Optimized for mobile devices
  - Simple, distraction-free layout
  - Fast loading with Vite
